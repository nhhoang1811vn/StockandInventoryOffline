# Stock & Inventory Manager — Windows

Stock & Inventory Manager for Windows 10 / 11 (64-bit). No installation needed.

## How to open the app

1. Download `StockandInventory-Windows-x64.zip`.
2. Right-click the zip, choose **Extract All...** and pick a folder (for example
   `C:\StockandInventory`).
   Do not run the app from inside the zip: it will not start.
3. Open the extracted folder and double-click **`StockandInventory.exe`**.
4. Keep all files in the folder together. You can create a desktop shortcut to
   `StockandInventory.exe`.

If Windows shows **"Windows protected your PC"** (the app is not code-signed yet), click **More
info**, then **Run anyway**.

An internet connection is needed for sign-in, cloud backup and restore.

## Your data

Data is stored locally in `main.db` under `Documents\AppViet_GoodManager\`.
Copy that folder to back up your data by hand. Deleting the app folder does not delete your data.

## Not available on Windows yet

- Barcode scanning with the camera.
- Taking a photo with the camera (choose an image file instead).
- Sign in with Google or Apple (email sign-in works).
- Buying Pro (free-tier limits apply).
- Low-stock notifications.

# Stock & Inventory Manager — bản Windows (Tiếng Việt)

Dành cho Windows 10 / 11 (64-bit). Không cần cài đặt.

## Cách mở ứng dụng

1. Tải file `StockandInventory-Windows-x64.zip`.
2. Chuột phải vào file zip, chọn **Extract All...** (Giải nén) và chọn một thư mục (ví dụ
   `C:\StockandInventory`).
   Không chạy trực tiếp từ bên trong file zip, ứng dụng sẽ không khởi động.
3. Mở thư mục vừa giải nén và nhấp đúp vào **`StockandInventory.exe`**.
4. Giữ nguyên tất cả các file trong thư mục. Bạn có thể tạo shortcut ra Desktop cho
   `StockandInventory.exe`.

Nếu Windows hiện cảnh báo **"Windows protected your PC"** (ứng dụng chưa được ký số), bấm **More
info**, rồi **Run anyway**.

Cần kết nối internet để đăng nhập, sao lưu và khôi phục trên đám mây.

## Dữ liệu của bạn

Dữ liệu lưu trên máy trong file `main.db` tại `Documents\AppViet_GoodManager\`.
Hãy sao chép thư mục này để tự sao lưu. Xoá thư mục ứng dụng sẽ không xoá dữ liệu.

## Chưa hỗ trợ trên Windows

- Quét mã vạch bằng camera.
- Chụp ảnh bằng camera (hãy chọn file ảnh).
- Đăng nhập bằng Google hoặc Apple (đăng nhập bằng email vẫn dùng được).
- Mua gói Pro (áp dụng giới hạn của bản miễn phí).
- Thông báo sắp hết hàng.
