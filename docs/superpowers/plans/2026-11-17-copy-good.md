# Copy a Good Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add "Copy" to the Good long-press menu: pick Store and Group in a dialog, then open `save_good` pre-filled with a copy of the Good.

**Architecture:** A pure function builds the copied `Good`. `GoodsCubit` exposes it through the existing `OpenSaveGoodPageState`. A new dialog widget (opened from `GoodsView`) collects Store and Group; its Group row reuses the existing `select_group` page, which gets an optional `storeId` argument.

**Tech Stack:** Flutter, flutter_bloc (Cubit + freezed), injectable/get_it, easy_localization, flutter_test.

**Spec:** [docs/superpowers/specs/2026-11-17-copy-good-design.md](../specs/2026-11-17-copy-good-design.md)

## Global Constraints

- Follow AGENTS.md: no business logic in widgets; touch only what is needed; no new dependency; domain terms **Store**, **Good**, **Group**.
- Copied Good keeps: description, barcode (as is), purchase price, sale price, min quantity, pictures. Name = source name + `" (copy)"` (literal, not translated). `id` null, `quantity` 0, no Document/Transaction history.
- Nothing is written to the database until the user presses Save in `save_good`.
- Changing the Store in the dialog resets the Group to "No group".
- `select_group` changes are additive: callers that do not pass `storeId` behave exactly as before; existing callers read only `groupId` from the result.
- New translation key `action_copy` goes in all 11 files in `assets/translations/` (edit JSON directly). Existing keys reused: `select_store`, `group`, `no_group`, `ok`, `cancel`.
- Do not hand-edit `lib/di/di.config.dart` or `*.freezed.dart`; run `dart run build_runner build --delete-conflicting-outputs`.
- Commits are made only if the user asks; this plan has no commit steps.

## Review Focus

- Source Good with null barcode / prices / minQuantity → the copy keeps them null (not `0`, not `"null"`). Pinned in Task 1.
- Copy's picture list is independent of the source's: editing the copy's `files` must not change the source. Pinned in Task 1.
- Source Good already named "X (copy)" → copy becomes "X (copy) (copy)" (no de-duplication, by design). Pinned in Task 1.
- User leaves `select_group` with the back button (null result) or dismisses the dialog by tapping outside → nothing changes / nothing opens. Task 4 step 3 and manual check.
- A locale file missing `action_copy` would show the raw key in the menu. Pinned by the parity test in Task 4.
